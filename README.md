# calculator
계산기 과제 수행<br>
<br>
## 작업내용
- 사칙연산으로 연산하기 <br>
- exit 입력할때까지 계산 반복 <br>
- 연산 결과 값들 저장 / 연산결과 값은 게터로만 접근 가능 <br>
- 가장 먼저 연산했던 결과값 제거 기능 <br>
- history 입력을 통해 저장값 조회 가능 <br>
- remove 입력을 통해 가장 오래된 결과값 삭제 가능 <br>
- 나눗셈 연산시 분모 0이 오면 경고문구 발생 <br>
<br>

## 테스트
[v] 연산이 잘 되는가 <br>
[v] 나눗셈 연산시 num2에 0이 입력되면 경고문이 발생하는가 <br>
[v] history 입력시 저장된 결과값 조회가 되는가 <br>
[v] remove 입력시 가장 오래된 값이 제거되는가 <br>
[v] exit 입력시 종료되는가 <br>
<br>
